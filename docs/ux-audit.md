# UI/UX 全量走查与改进记录

> 日期：2026-11-15  
> 范围：Funds、Market、Portfolio、Research，桌面与移动端，浅色与深色主题

## 结论

本轮以真实用户认知负担和操作效率为标准，完成四页及其主要抽屉、表单、搜索、筛选、排序、图表、主题切换和移动端交互走查。

已解决会直接影响可访问性、移动端操作和投资决策信息完整性的高优先级问题。剩余事项集中在表单草稿保护、字段级校验和部分信息的二级下钻，已整理为可执行 backlog。

当前没有已知的严重或无严重等级 axe 可访问性问题；Chromium 桌面与移动端完整 T3 回归通过。

## 高优先级修复

### 抽屉可访问性

- 打开抽屉时对 `#app` 设置 `inert`，避免键盘和辅助技术继续访问背景。
- Tab 与 Shift+Tab 在抽屉内循环，Escape 关闭，点击遮罩关闭。
- 关闭后恢复触发按钮焦点；卸载时清理事件监听、body overflow 和 inert 状态。
- 桌面表单使用右侧抽屉，移动端使用底部 sheet 并保留安全区。

验证：`test/e2e/drawer-a11y.spec.ts`

### 移动端触控

- 按钮、图标按钮、segmented control、chip、搜索框、输入控件和顶部操作达到至少 44×44px。
- 底部导航、抽屉 footer 和 toast 避开 `safe-area-inset`。
- 移动端状态、日期、限购和卡片元数据提高字号。

验证：`test/e2e/drawer-a11y.spec.ts` 的移动端命中区断言。

### 基金申购状态历史

- 基金详情默认份额新增“申购状态变化”，按日期由新到旧展示状态和单日限购。
- 暂停申购、限购未公布、开放不限额分别使用明确文字，不只依赖颜色。
- ETF 和无历史数据提供符合语义的空状态。

验证：`test/e2e/fund-detail-status.spec.ts`

### Research 认知负担与破坏性操作

- 知识卡默认折叠，保留筛选和完整内容。
- 英文分类 slug 改为中文标签，箭头表达可展开状态。
- 删除笔记、观察项和策略前统一确认。
- 笔记搜索无结果时提供“清空搜索”恢复路径。

验证：`test/e2e/research.spec.ts`

### 搜索与导航

- Funds 页不再同时出现全局基金搜索和本地目录搜索。
- Funds 搜索现在跨当前场外/场内分组的所有分类，并在结果中显示类别徽标。
- 其他页面仍可用全局搜索直接跳转 Funds。
- Market 分区锚点不再改写 Vue Router hash，并显示当前分区。
- skip link 和页面切换后的键盘焦点行为已修正。

验证：`test/e2e/navigation.spec.ts`、`test/e2e/market.spec.ts`

### Market 行情终端专项

- 全球指数与纳斯达克 100 pulse 卡改用语义涨跌底色（`surface-up` / `surface-down` / `surface-flat`），随「红涨绿跌 / 绿涨红跌」设置与深浅主题切换。
- VIX、美国 10 年、纳指 PE 等无直接涨跌方向的指标保持中性底色，避免误套红绿。
- 宏观区只保留美债 2/10/30 年与美元指数，不再重复顶部已有的 VIX、纳指 PE。
- 全球指数彼此独立，不再显示合计涨跌家数或平均涨跌幅，避免把独立市场揉成一个无意义汇总。
- 指标卡按数据类型显示新鲜度：实时、最新收盘、延迟、月度、陈旧、暂无数据；保留原始 `as_of`，未改写日期。
- 指数实时行情只覆盖有报价源的 9 个指数；`实时 / 延迟 / 最新收盘` 按交易所时间戳判断，抓取时间只作为「行情刷新于」说明，美股收盘数据不会再被标成当天实时。
- 货币对使用明确映射（USD / CNY、USD / JPY、CNY / HKD、USD / HKD），不再字符串拼接。
- 黄金多市场区分独立来源与折算参考：优先展示金投网 Au9999 与新浪伦敦金 XAU/USD；只有独立 XAU 存在时才计算折合国内价与国内溢价，缺失时回退折算并显示脚注。
- 品牌金价补充「品牌 / 足金饰品 / 投资金条」列标题。
- DCA 文案改为「恐慌贪婪指数决定档位，VIX 校验波动，纳指100 TTM PE 补充估值参考」；恐慌贪婪缺失时显示「无法生成有效策略」，不再默认 50 后给出常态定投建议。

验证：`test/e2e/market.spec.ts`、`test/e2e/realtime.spec.ts`、`test/e2e/accessibility.spec.ts`、`test/frontend/dca.spec.ts`、`test/frontend/market.spec.ts`、`test/frontend/market-freshness.spec.ts`

### 与线上旧版的功能对齐

- 恢复 7 只默认自选，并兼容旧版 `qdii-favs` / `qdii-favs-hidden` 本地键。
- 申购状态与每日限购合并为老版单列“申购”：徽标直接显示“限 ¥金额 / 暂停 / 开放”，悬浮提示补充币种、共用份额和核验范围；点击该列按每日限购排序。

- 份额表的申购徽标增加与买入/卖出规则一致的悬浮窗，展示该份额自己的申购状态与限额历史；D/I 等非默认份额可独立查看，不串用 A/C 历史。

- 净值日期只保留在表头；列表和移动卡片不再逐行重复日期。
- 买入规则显示原费率、代销 1 折价、固定费用和综合年费率。
- 卖出规则显示完整持有期限档位和免赎回费天数。
- 全部份额表补充买入费、综合费率和卖出规则。
- 数据降级提示列出缺少价格的份额代码与名称。
- 恢复年度与月度数字热力图，每个单元格直接显示百分比。
- 顶部恢复 GitHub 图标；全站一级导航、页面眉题和抽屉标题统一为简体中文。
- Research 笔记支持安全 Markdown 链接渲染和独立 `.md` 下载。
